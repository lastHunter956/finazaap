# Tarea T3.3 — Endurecimiento Android (`build.gradle`, `AndroidManifest`, `FLAG_SECURE`, Widget y Logs)

- **ID:** `T3.3`
- **Ola:** 3 (Seguridad) — **Requiere Decisiones `D3`, `D4`, `D6`, `D7` y aprobación explícita**
- **Nivel de modelo recomendado:** `fuerte`
- **Alto riesgo / Revisión humana:** **SÍ — ALTO RIESGO + ARCHIVOS PROTEGIDOS (Firma Release y `applicationId`)**
- **¿Toca archivos protegidos?:** **SÍ** (`android/app/build.gradle`, `android/app/src/main/AndroidManifest.xml`)
- **Hallazgos asociados:** `SEC-04`, `SEC-07`, `SEC-09`, `SEC-10` (Kotlin), `SEC-13`

## Objetivo
1. `android/app/build.gradle` (según `D3` y `D4`): configurar `signingConfigs.release` desde `key.properties` fuera de Git y actualizar `applicationId` si el usuario aprobó el cambio en `D3`.
2. `android/app/src/main/AndroidManifest.xml` (según `D7`): añadir `android:allowBackup="false"` y `android:fullBackupContent="false"`.
3. `MainActivity.kt`: aplicar `WindowManager.LayoutParams.FLAG_SECURE` cuando corresponda (`D6`).
4. `FinazaapWidgetProvider.kt`: eliminar `Log.i` con `income`/`expense`/`balance` (`SEC-10`) y enmascarar saldos si el modo privacidad está activo (`SEC-09`).
5. `home.dart`: validar estado de autenticación antes de abrir `AddExpenseScreen` desde deep link `finazaap://add_operation`.
6. `bank_whitelist_service.dart`: excluir `com.moneo.simulated.bank` de `defaultBankList` cuando `!kDebugMode`.
