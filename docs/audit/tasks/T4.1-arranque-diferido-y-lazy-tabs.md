# Tarea T4.1 — Arranque Diferido (`main.dart`) y Lazy Mounting en `MainContainer`

- **ID:** `T4.1`
- **Ola:** 4 (Fluidez y Performance)
- **Nivel de modelo recomendado:** `ligero`
- **Alto riesgo / Revisión humana:** No
- **¿Toca archivos protegidos?:** No
- **Hallazgos asociados:** `P1.1`, `P3.2`

## Objetivo
1. `lib/main.dart`: ejecutar en paralelo (`Future.wait`) únicamente lo necesario para el primer frame (`PrefsManager`, `initializeDateFormatting`, `CurrencyHelper`, `ThemeNotifier`, caja `data`); diferir `NotificationService.scheduleAllNotifications()` y `NotificationPipelineService.instance.initialize()` a `addPostFrameCallback`; mover `FlutterGemma.initialize()` a carga lazy bajo demanda en `AiChatService`.
2. `lib/Screens/main_container.dart`: implementar carga diferida (lazy mounting) de pestañas no visitadas (`_loadedTabs = {0}`) manteniendo el estado una vez montadas, y pasar `isActive` a `Statistics` / `CategoriesScreen` para evitar trabajo de render en pestañas ocultas.
3. `lib/Screens/categories_screen.dart`: evitar trabajo innecesario en `didUpdateWidget` cuando la pestaña no está activa.
