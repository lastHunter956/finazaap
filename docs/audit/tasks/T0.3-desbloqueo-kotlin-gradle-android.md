# Tarea T0.3 — Desbloqueo de Kotlin/Gradle Android y Verificación de Manifest Release

- **ID:** `T0.3`
- **Ola:** Pre-Ola 3 (o previa a cualquier build Android `--release`) — **Requiere aprobación explícita**
- **Nivel de modelo recomendado:** `ligero`
- **Alto riesgo / Revisión humana:** **SÍ** (toca configuración Gradle de Android)
- **¿Toca archivos protegidos?:** No directamente (`android/build.gradle` no está en la lista de 6 rutas, pero afecta compilación Android junto con `android/app/build.gradle`)
- **Hallazgos asociados:** `M5`, `SEC-04`, `SEC-07`

## Objetivo
Resolver la discrepancia entre `android/settings.gradle:22` (`org.jetbrains.kotlin.android` `2.1.0`) y `android/build.gradle:2,15` (`ext.kotlin_version = '1.9.22'` / `force "org.jetbrains.kotlin:kotlin-gradle-plugin:1.9.22"`), que bloquea `:app:processReleaseMainManifest` en Flutter `3.44.2`, para luego inspeccionar el `AndroidManifest.xml` fusionado de la variante `release`.

## Bloqueo documentado en Ola 0
- **Versiones efectivas:** Flutter `3.44.2` (Dart `3.12.2`), Java `OpenJDK 17.0.19`, Gradle `8.7`, AGP `8.6.0`, Kotlin plugin `2.1.0` en `settings.gradle` forzado a `1.9.22` en `build.gradle`.
- **Error:** `Your project's Kotlin version (1.9.22) is lower than Flutter's minimum supported version of 2.0.0.`

## Archivos
- **Permitidos (previa aprobación):** `android/build.gradle`, `android/settings.gradle`.
- **Prohibidos:** `android/app/build.gradle`, `android/app/src/main/AndroidManifest.xml`, `lib/`.

## Prueba de verificación y criterio de aceptación
- `./gradlew :app:processReleaseMainManifest --no-daemon` finaliza con `RC=0` en Docker.
- Se inspecciona `build/app/intermediates/merged_manifests/release/AndroidManifest.xml` registrando si `INTERNET` y `allowBackup` están presentes.

## Comandos Docker
```bash
docker-compose exec -T flutter-env bash -c 'cd /app/android && ./gradlew :app:processReleaseMainManifest --no-daemon'
```

## Riesgos, retroceso y qué NO hacer
- **Qué NO hacer:** No cambiar `applicationId`, firma ni permisos en esta tarea.
- **Retroceso:** `git revert` en rama `agent/*`.
